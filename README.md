# Backrooms: Escape

A browser horror game built with Three.js. Collect his four gadgets, find the exit, and survive.

## Play locally
Open `index.html` in a desktop browser (Chrome or Firefox). It loads Three.js from a CDN, so you need internet access.

## Put it on GitHub Pages
1. Create a new repository and add `index.html` and this README.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
3. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.

## Controls
WASD move · Shift sprint · Mouse look · 1 Chore list · 2 Homework · 3 Money · 4 Bath water

## 3D models
`models/monster.glb`, `models/items.glb` and `models/environment.glb` are generated by `python3 tools/make_models.py` (needs numpy).
Import any of them in Blender (File > Import > glTF 2.0), edit, and export over the same file name. Keep these node names so the game can animate them:
- monster: Head, Face (material named `Face` gets the uploaded photo), Chest, ArmL/ArmR, ForearmL/ForearmR, LegL/LegR, ShinL/ShinR, Spider, SpiderLeg0-7, SpiderKnee0-7, SpiderAbdomen
- items: ipad, computer, iphone, vr, chore, homework, money, bath, sonar
- environment: locker (with a `Door` child), table, crate, barrel, ceilinglight

Serve over http (`python3 -m http.server`) or GitHub Pages; opening index.html from disk blocks model loading and the game falls back to its built-in shapes.

Environment also has `trim`, `vent`, `outlet` (wall decoration), `cabinet` and `chair`. Item and wall textures are painted in code (see `PAINT` in index.html) onto materials by name.

## Phone
Open the Pages link on a phone (landscape works best). Left stick moves, drag the right side to look; buttons: JUMP (also BREATHE while hiding), RUN (hold), CROUCH (slide while running), HIDE, LIGHT, and the five item buttons. Add `?touch` to the URL to force touch controls on any device.
